## Recommended test: perturb the prior to generate proposals, then restore the original objective

The primary question should be:

> **Can small multiplicity-prior perturbations generate useful alternative solutions that improve clustering after they are optimized and scored under the original prior?**

Run prior sensitivity as a separate experiment. Otherwise, improved search and a changed statistical model will be confounded.

I rechecked the repository: the default-branch revision is still **`da651879c2a33f481957ffae1d1c865d11ad39c8`**. Pin the experiment to that commit and record any experimental patch separately. 

The following is a proposed test protocol—not completed validation.

# 1. Freeze the baseline and define the claims

The current compiler uses a uniform prior on integer multiplicities \(1,\ldots,M_i\), with \(M_i\leq4\). The production estimator uses a complete graph with pilot-derived weights and the original mutation-specific CCF bounds.  

Write the original raw objective as

\[
F_\lambda^0(\boldsymbol\phi)
=
\sum_i f_i^0(\phi_i)
+
\lambda\sum_{i<j}w^0_{ij}|\phi_i-\phi_j|.
\]

For an explicit partition \(P\), retain the existing secondary score:

\[
S^0(P)
=
2L_{\mathrm{refit}}^0(P)
+
K\log N
-
1.4\log\operatorname{PartitionMass}(P).
\]

The experiment must distinguish three outcomes:

| Claim | Evidence required |
|---|---|
| **Search improvement** | A lower attained \(F_\lambda^0\) at the **same absolute \(\lambda\)**, using the same graph, prior, bounds, and qualification rules |
| **Partition-score improvement** | A lower \(S^0(P)\) after fresh original-prior membership refitting |
| **Scientific improvement** | Better clustering and CCF accuracy on independently generated, held-out tumors |

**Do not substitute one claim for another.** A lower raw objective need not produce a lower partition score, and either score can improve while accuracy worsens.

For every paired experiment, freeze the input mutations, exclusions, count arrays, CN inputs, purity, multiplicity support, CCF bounds, clipping, fusion tolerance, solver tolerances, and partition-refinement policy. Changes to graph weights or lambda selection belong only in the explicitly identified sensitivity arms.

# 2. Fix the perturbation policy before examining results

Use normalized, bounded log-prior perturbations:

\[
\boxed{
\pi^{(b,\eta)}_{im}
=
\frac{
\pi^0_{im}\exp\{\eta\xi^{(b)}_{im}\}
}{
\sum_{k\in\mathcal M_i}
\pi^0_{ik}\exp\{\eta\xi^{(b)}_{ik}\}
}
}
\]

with

\[
\xi^{(b)}_{im}\sim\operatorname{Uniform}(-1,1).
\]

Use these settings:

| Setting | Prespecified value |
|---|---|
| Primary perturbation magnitude | **\(\eta=0.03\)** |
| Magnitude sensitivity | \(\eta\in\{0.01,0.03,0.05\}\) |
| Random directions | Four independently generated arrays |
| Paired opposite directions | Include both \(\xi^{(b)}\) and \(-\xi^{(b)}\), giving **eight perturbed priors per magnitude** |
| Maximum retained starting vectors | **Four** |
| Master proposal seed | `2026092600` |
| Randomness within a fit | None: each prior realization stays fixed |

The maximum change in prior odds is

\[
\frac{\pi^\eta_{im}/\pi^\eta_{ik}}
{\pi^0_{im}/\pi^0_{ik}}
\in[e^{-2\eta},e^{2\eta}].
\]

Thus, the three magnitudes permit maximum upward odds changes of approximately **2.02%, 6.18%, and 10.52%**, respectively. These are experimental settings, not established optimal values.

Generate noise using a reproducible key containing the tumor identifier, mutation identifier, multiplicity, and direction index. Save the actual perturbation arrays and their hashes. Do not rely solely on a process-global random seed.

**Important invariants:** multiplicity candidates do not change; invalid candidates remain invalid; single-candidate rows remain unchanged; and \(\eta=0\) returns the original prior without additional normalization arithmetic.

# 3. Use these experimental arms

The repository already has an optional partition estimator with whole-group birth and multi-seed search. Perturbations must therefore be compared against that machinery—not only against the older raw-output baseline. 

## 3.1 Primary arms

| Arm | Definition | Purpose |
|---|---|---|
| **R: raw baseline** | Existing production raw fit, unchanged | Reference raw path, graph, and lambda selection |
| **B: current partition baseline** | Existing `--partition-search`, `birth_mode="single_cluster"`, `seed_bank_size=1`; retain the existing grouping convention | Main accuracy comparator |
| **P: perturbation proposals** | B plus up to four starting vectors derived from perturbed-prior pilots; all subsequent fitting, refitting, and selection use the original prior and graph | Test the proposed mechanism |
| **D: deterministic proposals** | B plus up to four multiplicity-guided deterministic starting vectors; otherwise identical to P | Control for simply adding more starts |

The existing birth estimator preserves the primary raw output and reports its additional partition estimate separately. Retain that separation in this experiment. 

### Exact construction of arm P

First, compute the eight perturbed-prior pilot vectors at \(\eta=0.03\):

\[
\tilde{\boldsymbol\phi}^{(b)}
=
\arg\min_{\boldsymbol\phi\in\mathcal B}
\sum_i f_i^{(b,0.03)}(\phi_i).
\]

Use the existing qualified scalar solver. An unresolved auxiliary pilot is recorded as unresolved and is not silently replaced.

Remove duplicate starting vectors, using a prespecified maximum-coordinate difference of \(10^{-8}\). Retain at most four vectors through deterministic farthest-point selection:

\[
d(x,y)
=
\sqrt{\frac1N\sum_i(x_i-y_i)^2}.
\]

Start the distance calculation from the original pilot; choose the most distant remaining vector, then repeat using distance to the already selected set. Break ties by direction index. This selection uses neither truth nor accuracy.

Next, choose **three consecutive positive penalties from R’s recorded path**, centered as closely as possible on R’s selected penalty. At a boundary, use the first or last three positive penalties. When R selects zero, use the first three positive penalties. Use all available positive penalties when fewer than three exist.

At each selected penalty, solve the **original** objective from each retained starting vector:

\[
\hat{\boldsymbol\phi}^{(b)}_\lambda
=
\operatorname{Solve}
\left(
F_\lambda^0;
\text{start}=\tilde{\boldsymbol\phi}^{(b)}
\right).
\]

This gives at most **12 additional raw-start solves per tumor**.

For every qualified result, extract its memberships, deduplicate memberships, and perform fresh original-prior refitting. Apply the same four-round reassignment/refit budget to each distinct additional partition. Do not introduce another birth generation for these new candidates in this first experiment.

Finally, select from the union of B’s preserved incumbent and the new qualified partitions using \(S^0\).

**Keep R’s original continuation and outputs unchanged.** These are side experiments attached to a completed baseline fit, not changes to its continuation trajectory.

### Exact construction of arm D

Let \(s_i\) denote the scale in \(p_{im}(\phi)=\operatorname{clip}(s_i m\phi)\). Construct four starts:

\[
x_i^{(k)}
=
\operatorname{clip}_{[L_i,U_i]}
\left[
\frac{a_i/(a_i+r_i)}
{s_i\,\min(k,M_i)}
\right],
\qquad k=1,2,3,4.
\]

These multiplicities are used **only to construct starting vectors**. Optimization still uses the full marginalized likelihood.

Deduplicate starts and apply exactly the same three penalties, qualification rules, membership extraction, refitting, and refinement budget as P. Do not pad duplicate starts merely to increase the nominal count.

This is an equal-start-budget comparator. Report actual computation as well, because equal numbers of starts do not guarantee equal runtime.

## 3.2 Separate sensitivity arms

On a smaller mechanistic panel, use a \(2\times2\) design:

| Arm | Likelihood prior | Graph weights |
|---|---|---|
| **S00** | Original \(\pi^0\) | Original \(W^0\) |
| **S10** | Perturbed \(\pi^\eta\) | Original \(W^0\) |
| **S01** | Original \(\pi^0\) | Perturbed-pilot \(W^\eta\) |
| **S11** | Perturbed \(\pi^\eta\) | Perturbed-pilot \(W^\eta\) |

Use the **same absolute penalty and common numerical starting-vector bank** across these four arms. This separates likelihood effects, graph effects, and their interaction.

The current graph depends on pilot distances, a pilot-spacing floor, and mean-weight normalization, so graph sensitivity is not equivalent to changing only edges incident to a switched mutation. 

Do not rank these arms by their own different objective values. Compare their estimates and accuracy; evaluate returned vectors under \(F_\lambda^0\) as an additional common-reference diagnostic.

# 4. Stage 0: mathematical and implementation tests

Complete these before cohort fitting.

| Test | Required check |
|---|---|
| **Zero perturbation** | Original priors, numerical outputs, memberships, and selection are unchanged in the same execution environment |
| **Normalization and support** | Every valid row sums to one; no invalid candidate receives mass |
| **Single-candidate rows** | Prior and mutation-level likelihood are unchanged |
| **Common-offset invariance** | Adding the same perturbation to all multiplicities in a row has no effect after normalization |
| **Odds bound** | Every pair of valid candidates satisfies the \(e^{\pm2\eta}\) bound |
| **Permutation reproducibility** | Reordering TSV rows does not change the ID-indexed perturbation or canonical result |
| **Model immutability** | In-place prior changes are rejected; auxiliary models have distinct identities |
| **Certificate isolation** | Perturbed-prior certificates and refit caches cannot be attached to original-prior results |
| **Failure preservation** | An auxiliary failure retains B’s incumbent and records incomplete additional coverage |
| **Output separation** | Additional partition results do not overwrite the raw baseline tables |

For the single-candidate test, distinguish mutation-level invariance from whole-fit invariance. In a mixed-support tumor, an \(M_i=1\) mutation can still move because it is coupled to other mutations. **An entirely single-candidate tumor is the whole-pipeline negative control.**

### Likelihood identity test

At fixed \(\phi\), compute the original conditional posterior

\[
q^0_{im}(\phi)
=
\frac{\pi^0_{im}e^{\ell_{im}(\phi)}}
{\sum_k\pi^0_{ik}e^{\ell_{ik}(\phi)}}.
\]

Independently verify

\[
f_i^\eta(\phi)-f_i^0(\phi)
=
\log\sum_m\pi^0_{im}e^{\eta\xi_{im}}
-
\log\sum_m q^0_{im}(\phi)e^{\eta\xi_{im}}.
\]

Also verify the consequence

\[
|f_i^\eta(\phi)-f_i^0(\phi)|\leq2\eta.
\]

Test random interior points, original bounds, and represented clipping breakpoints. Compare loss and posterior calculations against an independent evaluator. Check gradients away from clipping kinks and one-sided derivatives at the kinks.

For moderate-depth unit fixtures, use an initial loss-comparison tolerance of

\[
10^{-10}+10^{-12}|\text{reference value}|.
\]

This is a proposed unit-test tolerance, **not a relaxation of any production qualification tolerance**.

# 5. Stage 1: controlled mechanism fixtures

Use six fixture families. They should test the mechanism before measuring mean cohort accuracy.

| Family | Construction | Question |
|---|---|---|
| **No ambiguity** | All \(M_i=1\); include one- and multiple-cluster examples | Does perturbation correctly have no effect? |
| **Two separated aliases** | One mutation with \(a=120\), total depth \(400\), \(s=0.4\), support \(\{1,2\}\) | Can a small prior tilt switch the preferred well near \(0.375\) versus \(0.75\)? |
| **Anchored ambiguity** | Combine aliasing mutations with single-copy mutations supporting a shared CCF | Does shared evidence overcome an arbitrary local tilt? |
| **False-split control** | True \(K=1\), high ambiguous-support fraction; test common CCF \(1.0\) and \(0.6\) separately | Does independent noise create artificial clusters? |
| **Aliased true clusters** | Two true CCF groups whose multiplicity-adjusted VAFs overlap | Does an alternative initialization expose a useful partition? |
| **Bounds and support stress** | Mixed supports \(1\)–\(4\), balanced amplification, LOH, heterogeneous upper bounds including \(U_i<1\), and extreme counts | Are feasibility and numerical qualification preserved? |

For the isolated alias fixture, evaluate both perturbation directions explicitly:

\[
\xi=(-1,+1)
\quad\text{and}\quad
\xi=(+1,-1),
\]

at \(\eta=0.01\). Independently bracket and minimize each known well rather than trusting a single local minimizer.

A mode switch in this fixture is **not** an accuracy success. It verifies that small prior perturbations can change a nearly tied mode ranking.

For each fixture, save the original and perturbed well locations, well losses, posterior multiplicities, pilot changes, qualified raw candidates, and selected partitions.

**Do not require cross-device CCF equality at effectively tied minima.** Require valid qualifications and objective agreement, and explicitly classify the tie. PyTorch does not guarantee bitwise-identical results across CPU/GPU or platforms, even for identical inputs. :chatgpt-content-reference{index="6"}

### Distinguish feasible-score improvement from proved refit ordering

For partition \(P\), let \(\hat L(P)\) be its attained refit loss and \(g(P)\) the total scalar optimality-gap bound. Then use

\[
S_{\mathrm{lower}}(P)
=
2[\hat L(P)-g(P)]+C(P),
\]

\[
S_{\mathrm{upper}}(P)
=
2\hat L(P)+C(P),
\]

where \(C(P)\) is the unchanged complexity/allocation term.

Declare refit ordering numerically established only when

\[
S_{\mathrm{upper}}(P_{\mathrm{new}})
<
S_{\mathrm{lower}}(P_{\mathrm{baseline}})
-\delta_{\mathrm{num}}.
\]

The current partition estimator already distinguishes published-score improvement from this stronger score-interval ordering claim. Preserve that distinction. 

For failed or worsened cases, perform an **offline true-membership refit** under the original prior. Keep it outside candidate generation and selection. This helps distinguish a missed good partition from an original criterion that prefers an inaccurate partition.

## Proposed acceptance gates

These thresholds are proposed research criteria, not existing repository policy.

| Gate | Requirement |
|---|---|
| **Correctness** | All Stage 0 invariants pass; every published additional result satisfies existing qualification rules |
| **Incumbent preservation** | P never publishes a worse evaluated original partition score than its preserved B incumbent beyond the numerical comparison allowance |
| **ARI improvement** | Mean paired ARI improvement over B is at least **0.01**, with the lower bound of a paired 95% confidence interval above zero |
| **CCF improvement** | At least **2% reduction** in tumor-averaged partition-refitted CCF MAE relative to B |
| **Specific benefit of perturbation** | P outperforms D on mean paired ARI with a lower 95% confidence bound above zero; otherwise, do not claim superiority over additional deterministic starts |
| **Cluster-count protection** | No decrease in observed exact-\(K\) count and no increase in observed false splits among true-\(K=1\) tumors relative to B |
| **Execution reliability** | No new loss of publishable results on cases where B succeeds; additional-search failures remain explicitly reported |
| **Cost for default adoption** | Median total runtime no more than **2× B**, 95th-percentile ratio no more than **3× B**, and peak device memory no more than **1.5× B** |

Define relative MAE reduction as

\[
100
\left[
1-
\frac{\frac1T\sum_t\mathrm{MAE}_{P,t}}
{\frac1T\sum_t\mathrm{MAE}_{B,t}}
\right].
\]

Use **10,000 paired bootstrap resamples of tumors**, stratified by the design cells, with evaluation seed `2026092699`. Report mutation-weighted summaries secondarily.

Perturbation replicates are not independent tumors and must not inflate the sample size.

A lack of observed additional false splits is a finite-panel result, not proof of zero false-split risk. Likewise, a failed confidence-interval gate means the claimed improvement is not established; do not silently retune on the confirmation panel.

The final report should conclude one of the following:

| Result | Conclusion |
|---|---|
| Pilots change, but original-objective fitting returns the same results | Prior sensitivity exists locally; no demonstrated search benefit |
| P improves over B but not D | Additional exploration helps; a special advantage of prior perturbation is not established |
| P improves original scores but worsens held-out accuracy | Better optimization does not resolve the statistical criterion’s failure |
| S10/S01/S11 change results substantially, while P adds little | Sensitivity comes mainly from changing the likelihood or adaptive graph |
| P passes accuracy, correctness, and cost gates | Support for adopting perturbation-generated proposals under the original final model |

**The first executable experiment should therefore be: \(\eta=0.03\), eight auxiliary pilot vectors, at most four retained starts, three baseline penalties, and paired B/P/D comparisons on the 108-tumor development panel.** Keep the original prior for all admitted final candidates, and require fresh held-out evidence before making this a default search policy.
